## Performance analysis

Project: users-s22

### Latency
Latency is the time between request and response.
We analyze P50, P95, P99 instead of average values.

High P99 latency indicates slow responses for a small percentage of users.

### Throughput
Throughput describes how many requests per second (RPS) the system can handle.

### Notes
Performance depends on CPU, memory and network saturation.
