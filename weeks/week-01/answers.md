## 1. **Ресурс vs коллекция**
Ресурс — один объект (`/users/1`).
Коллекция — набор объектов (`/users`).

## 2. **Почему POST и 201, а не 200?**
POST — создание нового объекта.
201 — означает «создано».
200 — просто «успешно», без факта создания.

## 3. **Идемпотентность**
Повторный запрос даёт тот же результат.
Идемпотентные методы:
GET, PUT, DELETE, HEAD, OPTIONS
POST — не идемпотентный.

## 4. **Почему ID генерирует сервер?**
Чтобы:
* гарантировать уникальность
* избежать конфликтов
* контролировать структуру данных

## 5. **Контракт API**
Это чёткое описание: какие URL, методы, форматы данных и ответы.
Важно, чтобы клиент и сервер «понимали» друг друга.

## 6. **Зачем OpenAPI (Swagger)?**
* документирует API
* генерирует UI для тестирования
* помогает фронту и бэку работать независимо
* позволяет генерировать клиентский код
